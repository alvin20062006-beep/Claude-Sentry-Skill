提醒只提供参考。项目不评分、不分级、不估算封号概率，也不猜测 Claude 的内部标记。Notices are for reference. Sentry does not score, assign risk levels, predict bans, or guess Claude’s internal account flags.

01

只观察你开启的网络变化Network observations are opt-in

启用查询后，ipwho.is 会看到运行端出口 IP，不会收到聊天内容。会话启动或提交消息时检查，不是持续监控。When enabled, ipwho.is sees the runtime’s outbound IP, never chat contents. Checks run at session start or prompt submission, not continuously.

02

本地状态，尽量少留Minimal local state

保存加盐 IP 摘要和少量提醒状态，不保存原始 IP 或聊天全文。本地记录不等于通知已送达。Stores a salted IP digest and limited notice state, not raw IP addresses or full chat text. A local record is not a delivery receipt.

03

查询失败，交流继续Detection can fail; conversation continues

检测失败不得阻断 Claude。每次成功观测到的 IP 变化都重新提醒，包括同国家换 IP 和 A→B→A。Detection failures must not block Claude. Every successfully observed IP change gets a fresh notice, including same-country changes and A→B→A.

A LITTLE MORE CONTEXT

你可能想问。Good questions.

会改变 Claude 的正常回答吗？Does Sentry change Claude’s normal answer?

规则要求正常回答永远优先。提醒只能附加或独立显示，不能改写、替代、暂停或阻断回答，也不要求额外确认。没有信号时，不添加任何内容。The rules always prioritize the normal response. Notices may be additional or standalone, but must not rewrite, replace, pause, or block the answer or ask for extra confirmation. With no signal, nothing is added.

需要本地模型或额外 API Key 吗？Do I need a local model or another API key?

不需要。内容解释由当前 Claude 完成，Hook 使用确定性的本地规则，不接入额外模型、数据库或模型 API。你仍需要正常使用 Claude 所需的环境。No. The current Claude interprets visible context; Hooks use deterministic local rules without an extra model, database, or model API. You still need your normal Claude setup.

可以配合 Auwait 网络工具使用吗？Can I use it with Auwait’s network tools?

可以。Auwait 网络工具的评分、封号相关信息是供用户独立参考的，与本项目的提醒用途不同。本插件不自动访问或采用网站的评分。Yes. Scoring and account-ban information on Auwait’s network tools is a separate reference for users, distinct from Sentry’s notices. The plugin does not automatically access or adopt its scores.

提醒是否代表违规或官方内部标记？Does a notice mean a violation or an internal flag?

不代表。提醒仅基于可观察信号，政策与地区数据是有日期的参考快照，应核对有效日期。没有提醒也不是安全保证。项目不提供申诉或账号恢复功能。No. Notices are based only on observable signals. Policy and region data are dated snapshots; check their effective dates. Silence is not a safety guarantee. This project does not provide appeals or account recovery.
