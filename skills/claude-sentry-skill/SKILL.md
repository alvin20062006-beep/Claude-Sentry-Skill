# Claude Sentry Skill v0.9.0 — Claude 通用 Skill

## 使用方式
本目录可以独立作为 Claude Skill 发布，也可由 Claude Code Plugin 加载。独立使用只依据当前 Claude 可见内容作解释；不会执行电脑上的 Hooks、自动查询出口 IP 或读取其他会话。用户明确调用时进行说明，或由 Claude 在判断相关时加载；不保证每轮调用。

## 唯一目标
在用户仍可正常使用 Claude 时，对**可观察、可说明依据的信号**作透明标记与简短提醒。避免把本地推断说成 Anthropic 后台真实判定。

## 正常回答优先
- Claude 按原请求和自身规则正常回答；本 Skill 不改写、替代、暂停或阻断正文，不额外要求拒绝、确认或对话步骤。
- 只有出现明确、可观察的信号时，才在正常回答之外附加一句简短提醒；没有信号就不添加任何内容，包括“无需提醒”“证据不足”等占位文字。
- 提醒可以放在回复末尾或由 Hook 独立显示；IP 变化、客户端错误等事件没有回答正文时，允许独立提醒，不要求 Claude 为此生成或重做回答。
- 同一信号合理去重；可见上下文中已提醒且没有新变化时不重复。每次成功观测到新的出口 IP 必须重新提醒，包括 A→B→A。
- Hook 检测失败不能影响正常回答；日志和测试输出不等于用户已收到通知。

## 规则一：只标记，不评分
- 不输出任何高/中/低风险等级、百分比、扣分、预测封号时间、官方 `flagged` / `priority` 的伪造值。
- **首次明确命中即可提醒**，不依赖累计对话次数或拒绝次数。
- 发现异常不代表已被 Anthropic 标记；没有提醒也不代表安全。

## 规则二：对话内容信号
综合考虑：
1. 关键词、敏感主题和公开政策分类（即使意图尚未充分明确，也可提示“涉及政策主题”）。
2. 用户实际要求获得的能力、用途、授权和执行程度。
3. 小说、虚构人物、角色扮演、研究、编码、翻译等表达方式：不因为使用了这些形式就自动放行，也不因此一律认定违规。
4. 已知的多轮上下文，以及 Claude 实际可见的安全拒绝或官方通知。仅在 Claude Code 插件已加载且 Hook 确实运行时，脚本才会读取其提供的本地会话记录，筛选历史线索并识别部分跨轮组合请求。独立 Skill 不具备这个自动读取能力。
5. 通过附件、文件、工具输出提出的请求：仅在确实可见时分析，不虚构文件内容。Hook 不会擅自解析任意附件与工具结果。
6. 内容与意图解释由当前 Claude 在可见上下文中完成；Hook 仅提供确定性的本地规则检测，不接入额外模型，不能保证理解所有隐含意图。

一个普通历史研究、文学创作或防御性讨论可以提到敏感词；可以给出**中性主题提醒**，但不得将其误写成“违规”“会封号”。不能提供规避安全审查或改写危险请求的技巧。

反诈识别、预防和举报等普通科普不因诈骗关键词本身触发提醒。封禁规则只针对请求绕过或规避账号封禁的操作意图；一般原因、合规预防和申诉讨论不因封号词汇触发。同一消息中另有操作请求时仍需分别判断。

## 规则三：地区合规信号（统一规则）
名称：`Unsupported Region Risk`。
- 按用户许可观察**运行 Hook 的环境**的出口 IP、国家代码、设备时区、以及实际可见的官方地区限制提示。
- **首次获得出口 IP → 提醒一次；每次 IP 改变 → 再提醒一次，即便国家和时区都不变。** IP 从 A→B→A，每次切换也提醒。
- 出口 IP 不变且相关可观察状态不变 → 不重复提醒。
- 仅时区变化 → “环境变化”提醒；时区自身不是不支持地区的确证。
- 当前国家代码未列入完整的现行官方 Claude 支持地区快照时 → 在本次检测有新信号时提醒核对。属地、特殊地区及官方名单变更不得直接推断为违规。
- 不展开 VPN、机房、VPS、旅行等原因假设；不凭用户语言、国籍或护照推断违规。
- **IP 查询必须由用户明确开启**；查不到 IP 就报告无法检测，不宣称持续监控。

## 规则四：提醒格式
在正常回答之外，只附一句，例如：`Claude 哨兵提醒：检测到出口 IP 已变化，仅供参考，不代表官方内部标记。`

依据必须是实际可见的内容或设备事件；不得声称已运行实际上没有运行的检测，不附带等级、分数或封号概率。提醒不能取代正文，也不要求用户先处理提醒才能继续。

## 规则五：只做封号前预警
- **不做**申诉、被封后恢复、账号解封指南，也不以历史封号倒推确切原因。
- 封号用户的公开案例仅可作为线索，必须说明哪些是事前可观察事实、哪些是自述或猜测。
- 官方文档生效日期必须核对；`POLICY_INDEX.json` 的生效日期为 2026-11-12。截至 2026-11-01，它仅供参考，不得当成现行规则；无法取得当时生效条款时，只解释中性主题并明确证据不足。

## 隐私与能力边界
- 普通 Skill 不会因此获得 Claude 的后台风控结果、操作系统网络权限或强制每条消息自动检查的能力。
- Claude Code Hook 可在指定生命周期事件运行本地代码；地区检查默认关闭，开启第三方查询时查询服务会看到出口 IP，**不上传聊天原文**。
- 默认不写入原始对话文本或原始 IP；为了检测变化，可在本地保存上次出口 IP 的加盐摘要及少量状态。
- 在网页/手机普通聊天里，用户可主动调用，Claude 也可能按相关性加载；不能承诺每轮自动检查或实时提醒。
- Hook 可以读取 Claude Code 提供的本地 `transcript_path`，但并不能获取或读取 Claude 网页/手机客户端的完整对话。
- 官方可见提示从 `Notification`、`StopFailure`、`Stop` 和用户消息提及的通知中提取，不能将用户转述视为官方验证结果；登录页面和其他软件界面不可被普通 Hook 自动读取。
- 本项目**只提醒，不暂停、不拦截、不要求确认、不改写消息**；检测失败时直接放行。

## 参考文件
- `references/context_rules.json` — Plugin 和独立 Skill 共用的 35 条中性内容规则；不是违规结论。
- `references/supported_regions.json` — 共用的离线地区快照，核对其日期；独立 Skill 不因此获得 IP 查询能力。
- `references/POLICY_INDEX.json` — 政策领域索引，核对政策的生效时间。
- `references/SCENARIOS.json` — 典型场景，不是内部敏感词清单。
- `references/PREBAN_EVIDENCE.json` — 事前可观察依据；不把申诉当成触发条件。
